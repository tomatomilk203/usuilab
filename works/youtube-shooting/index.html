WORKS / CHROME EXTENSION

YouTubeのコメントを、
ゲームの遊びに。

YouTube Shootingは、動画のコメントを弾幕として使うChrome拡張です。いつもの視聴画面に、遊びのレイヤーを重ねる自主制作プロジェクトです。

何をつくったか

動画のコメントを敵として表示し、避けたり撃ったりして遊ぶゲームです。Chrome Web Storeで公開しており、紹介ページと公開コードから、利用方法や構成を確認できます。クライアント案件ではなく、自主制作として紹介しています。

体験の中心は「動画の上で遊ぶ」

動画と別の画面へ移るのではなく、視聴中の画面にゲームを重ねます。導入後は動画を開き、STARTボタンから開始。難易度を選び、マウスまたはキーボードで移動します。射撃は自動で、プレイヤーは移動と回避に集中する構成です。

同じ動画でも、コメントがゲームの素材になります。既存コンテンツを別の体験として扱う発想が、このプロジェクトの核です。

公開物から分かる設計

  • 入口を短くする：紹介ページからChrome Web Storeへ直接移動し、インストール後の開始方法を案内しています。
  • 操作を絞る：自動射撃を採用し、初めて遊ぶ人も移動から始められます。
  • 難易度を分ける：EASY・NORMAL・HARD・HELLの4段階で、挑戦の幅を設けています。
  • 続ける理由をつくる：実績やコイン、機体スキンを用意し、繰り返し遊ぶ要素を加えています。

技術の構成

公開リポジトリのREADMEでは、Manifest V3、JavaScript、Canvas、YouTube Data API v3を構成要素として示しています。紹介するのは公開コードの技術構成であり、ストア版とリポジトリが常に同じバージョンであることまでは確認していません。

成果物と、まだ測れていないこと

確認できる成果物は、公開されたChrome拡張、紹介ページ、コードです。利用者の継続率や、どの操作で離脱するかの分析結果はここでは示していません。公開できたことと、ユーザーに継続して使われることは別の課題として扱います。

次に評価するなら「紹介ページからストアへ進んだ割合」「初回ゲーム開始」「繰り返し遊んだか」を分けて確認します。数字を出す場合は、期間・計測方法・対象を合わせて掲載する必要があります。

同じ考え方を、仕事に使うなら

「普段の作業や閲覧の流れに、小さな機能を足したい」という相談にも、利用場面・入口・最初の操作を分けて考えられます。拡張機能で実現できるか、独立したWebアプリがよいかは、必要な権限や利用環境を確認して判断します。
